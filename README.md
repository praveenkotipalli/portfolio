## Deploy with Docker (VPS)

The app builds into a standalone Node server (`output: "standalone"`), so the image ships without the full `node_modules`.

```bash
# on the VPS (Docker + Compose plugin installed)
git clone <repo-url> portfolio && cd portfolio
docker compose up -d --build        # serves on http://<server-ip>:3000

# update after pushing changes
git pull && docker compose up -d --build && docker image prune -f

# logs / status
docker compose logs -f
docker compose ps
```

Use `APP_PORT=8080 docker compose up -d --build` to publish on a different host port. For a domain with HTTPS, put a reverse proxy (Caddy or nginx) in front and point it at `localhost:3000`.
